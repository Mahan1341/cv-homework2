# Свои снимки для ДЗ 2

Здесь должны быть ваши фотографии: `01.jpg` … `18.jpg`, каждый меньше 1 МБ,
длинная сторона не больше 2000 px. В `corners.json` — четыре угла для первых
15 кадров и `null` для трёх негативных. Учебные изображения находятся отдельно
в `sample_data/`; этот каталог пока не содержит собственных снимков.

## План съёмки

Один лист A4 с текстом можно использовать на всех кадрах. Ракурс 30°/60° —
наклон камеры относительно съёмки прямо сверху; поворот 45° — в плоскости листа.

| № | Фон | Свет | Ракурс | Дополнительное условие |
|---|---|---|---|---|
| 01 | Тёмный стол | День | Почти прямо | Весь лист виден |
| 02 | Тёмный стол | День | Около 30° | Весь лист виден |
| 03 | Тёмный стол | День | Около 60° | Весь лист виден |
| 04 | Тёмный стол | Лампа сбоку | Поворот 45° | Тень и предмет на углу |
| 05 | Тёмный стол | Полумрак | Около 30° | Ручка пересекает границу |
| 06 | Светлый стол / подоконник | День | Почти прямо | Весь лист виден |
| 07 | Светлый стол / подоконник | День | Поворот 45° | Весь лист виден |
| 08 | Светлый стол / подоконник | Лампа сбоку | Около 30° | Палец на углу, тень |
| 09 | Светлый стол / подоконник | Лампа сбоку | Около 60° | На листе тень |
| 10 | Светлый стол / подоконник | Полумрак | Почти прямо | Слабый контраст |
| 11 | Пёстрый фон | День | Около 30° | Плитка / скатерть / клавиатура |
| 12 | Пёстрый фон | Лампа сбоку | Поворот 45° | На листе тень |
| 13 | Пёстрый фон | Полумрак | Около 60° | Посторонние линии |
| 14 | Пёстрый фон | Полумрак | Поворот 45° | Предмет на углу |
| 15 | Пёстрый фон | Лампа сбоку | Почти прямо | Посторонние линии и тень |
| 16 | Любой | Любой | Любой | Листа нет: книга / ноутбук / планшет |
| 17 | Любой | Любой | Любой | Лист выходит за кадр двумя углами |
| 18 | Любой | Любой | Любой | Сложный негатив: два перекрывающихся листа, мятый лист либо белый лист на белом столе |

План покрывает минимумы: по 5 кадров каждого фона; 6 при дневном свете,
5 с боковой лампой и 4 в полумраке; каждый ракурс минимум дважды;
4 кадра с перекрытием. Это план, а не описание уже снятых кадров:
после съёмки исправьте таблицу, если реальные условия отличаются.

Не ставьте `null` для обычного положительного кадра только из-за ошибки
детектора. На закрытом углу размечайте его предполагаемое положение.
На трёх запланированных негативных кадрах используйте клавишу `n`.

Подготовка и разметка из корня проекта:

```powershell
python prepare_data.py raw --out data
python docscan.py annotate data --ann data/corners.json
python run_experiments.py --data data --out out/personal --personal
```

Сначала уменьшение, потом разметка: координаты относятся к итоговым файлам.
В своём Classroom-репозитории эти снимки, разметку и `out/` нужно коммитить,
чтобы проверяющий мог воспроизвести числа.
